# mindmap v2 설계 — 다중 모듈 자기이해 지도

2026-10-23 작성. M1–M4(반응 패턴 8차원) 위에 방어기제·성격 특성 모듈, 통합 분석, 시각화와 부가 기능을 더합니다.

## 원칙 (AGENTS.md 재확인)

- 진단하지 않습니다. 모든 결과는 "현재 응답에서 보이는 경향"이며 고정된 유형이 아닙니다.
- 점수는 결정론적 코드(`lib/`)만 계산합니다. 설명 문구는 점수 구간·규칙에 연결된 정적 데이터입니다.
- 문항 데이터(`data/`)와 채점(`lib/`)과 화면(`components/`, `app/`)을 분리합니다.
- 강점과 어려움을 함께 보여주고, 병리화·수치심을 주는 표현을 쓰지 않습니다.

## 모듈

| 모듈 | 내용 | 문항 | 이론적 배경 |
| --- | --- | --- | --- |
| `reaction` | 갈등·평가 상황의 반응 패턴 8차원 (기존) | 32 | mindmap 자체 샘플 |
| `defense` | 방어기제 15종, 3개 수준 | 45 | Vaillant(1977, 1992)의 방어 위계, DSM-IV 방어기능척도(DFS), Andrews 외(1993) DSQ의 3요인 구조, Perry의 DMRS |
| `traits` | 성격 5요인 경향 | 20 | IPIP(public domain) Mini-IPIP(Donnellan 외, 2006) 문항을 한국어로 각색 |

방어기제 문항은 DSQ 문항을 옮기지 않은 **자체 작성 문항**입니다. 각 방어기제는 3문항이며 역채점이 없습니다. 같은 방어기제 문항이 연달아 나오지 않도록 고정 규칙으로 섞습니다.

### 방어 수준 표기

학술 용어(성숙/신경증적/미성숙)는 학습 페이지에서만 병기하고, 화면에서는 기능을 설명하는 이름을 씁니다.

| 수준 ID | 화면 이름 | 학술 명칭 | 방어기제 |
| --- | --- | --- | --- |
| `adaptive` | 성숙한 대처 | mature | 승화, 유머, 예상, 억제, 소속·도움 요청 |
| `inhibitory` | 내면 조정형 방어 | neurotic / mental inhibition | 주지화, 반동형성, 전치, 취소 |
| `immediate` | 즉각 보호형 방어 | immature | 부인, 투사, 합리화, 수동공격, 행동화, 회피·철수 |

모든 사람이 모든 수준을 상황에 따라 사용합니다. 즉각 보호형 방어도 강한 스트레스에서 마음을 지키는 기능이 있으며, 오래 반복될 때 관계·문제 해결 비용이 커질 수 있다는 점을 함께 설명합니다.

## 채점

공통 엔진 `lib/likert-engine.ts`: 응답 0–4 → 역채점 → 척도별 가중 평균 → `round(100 × Σwx / (4Σw))`. 누락·중복·알 수 없는 ID·범위 밖 값은 거부합니다. 기존 `scoreQuestionnaire`는 이 엔진에 위임합니다.

방어기제 파생 지표(`lib/defense-analysis.ts`):

- 수준 점수: 해당 수준 모든 문항의 정규화 평균.
- 무게중심: 반올림 전 수준 평균 A, I, M(적응·내면 조정·즉각)으로 `(3A + 2I + 1M) / (A + I + M)`을 1–3 범위에서 0–100으로 변환. 분모가 0이면 계산하지 않습니다. DMRS의 ODF에서 착안했지만 동일한 지표가 아닙니다.
- 개인 평균 대비: 15개 방어 점수의 평균과 각 점수의 차이. 응답 스타일(전반적으로 높게/낮게 답함)의 영향을 줄여 상대적으로 두드러진 방어를 보여줍니다.
- 두드러진 방어: 점수 내림차순(동점은 데이터 순서). 50점 이상만 후보로 하고, 1위와 5점 이내 차이는 "비슷한 수준"으로 함께 표시해 과잉 순위를 막습니다.
- 응답 패턴 참고: 모든 응답 동일, 평균 3.5 이상/0.5 이하. 결과를 무효화하지 않고 해석 주의만 안내합니다.

점수 구간: 0–24 드묾, 25–49 가끔, 50–74 자주, 75–100 두드러짐 (평균 응답 1·2·3 경계와 일치).

## 화면

- `/questions`: 모듈 허브(상태·문항 수·예상 시간), `/questions/[module]`: 공통 설문 컴포넌트.
- `/results`: 통합 대시보드와 마음 지도(마인드맵), `/results/[module]`: 모듈별 상세. `?example=1`은 고정 mock 응답 예시.
- 시각화: 반응 패턴 레이더, 방어 수준 사다리·무게중심 스펙트럼·개인 평균 대비 발산 막대, 5요인 양극 막대. 모든 차트는 같은 수치를 텍스트로도 제공하고 색상 외 정보(라벨·패턴)로 구분합니다.

## 부가 기능 (순차 구현)

1. 학습 사전 `/learn`: 방어기제별 정의·기능·대가·예시·성장 방향, 참고문헌.
2. 마음 기록 `/journal`: 상황 → 자동 생각 → 감정(강도) → 욕구 → 행동 → 방어 → 회복 기록. localStorage에만 저장, 전체 삭제 제공.
3. 결과 스냅샷·비교: 사용자가 저장을 선택한 결과만 localStorage에 보관, 두 시점 비교 차트.
4. 실천 카드 `/practice`: 결과 구간에 연결된 결정론적 연습 제안.
5. 리포트 인쇄·JSON 내보내기/가져오기.
6. 도움 받기 `/support`: 전문 도움 안내와 위기 연락처.

## 저장

설문 응답은 기존처럼 모듈별 sessionStorage 키(`selfmap.questionnaire`, `selfmap.defense`, `selfmap.traits`)에 저장합니다. 장기 기록(마음 기록, 스냅샷)은 사용자가 명시적으로 저장할 때만 localStorage에 둡니다. 서버·외부 API로 전송하지 않습니다.
