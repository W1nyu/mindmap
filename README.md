# SelfMap

반응 패턴, 방어기제, 성격 경향, 관계 애착을 하나의 마음 지도로 이어 보는 자기이해 도구입니다. 심리·의학적 진단이나 고정된 성격 유형을 제공하지 않습니다. 모든 점수는 결정론적 코드로만 계산하며, 문항은 검증된 임상 척도가 아닙니다.

## 실행

Node.js 20.9 이상과 npm이 필요합니다. API 키와 DB 없이 실행됩니다.

```powershell
npm.cmd install
npm.cmd run dev
```

[http://localhost:3000](http://localhost:3000)에서 확인합니다.

```powershell
npm.cmd run typecheck
npm.cmd run lint
npm.cmd test
npm.cmd run build
npm.cmd start
npm.cmd run smoke -- http://localhost:3000   # 실행 중인 서버의 경로·헤더·매니페스트·API 점검
```

## 모듈

| 모듈 | 문항 | 내용 | 근거 |
| --- | --- | --- | --- |
| 반응 패턴 | 32 | 평가 민감성 ~ 관점 회복의 8차원 | SelfMap 자체 샘플 |
| 방어기제 프로필 | 45 | 15개 방어기제 × 3문항, 성숙한 대처·내면 조정형·즉각 보호형 3수준 | Vaillant의 방어 위계, DSM-IV 방어기능척도 구분. 문항은 자체 작성(DSQ 문항 미사용) |
| 성격 5요인 경향 | 20 | 개방성·성실성·외향성·우호성·정서적 민감성 | IPIP(public domain) Mini-IPIP 한국어 각색 |
| 관계 애착 경향 | 12 | 관계 불안·친밀 회피 2차원(유형 판정 없음) | 성인 애착 2차원 모델(Brennan 외, 1998; Fraley 외, 2000) 참고, 자체 작성 |

각 모듈은 독립적으로 응답·채점하며, 마친 모듈만 통합 지도에 연결됩니다.

네 모듈이 ‘평소의 경향’을 본다면, **마음 상태 체크**(`/check-in`)는 ‘최근 2주의 상태’를 봅니다. 공개 척도인 WHO-5 웰빙 지표(WHO, 1998; Topp 외, 2015)의 5문장·6단계(0–5) 구성을 따르며, 문장은 SelfMap이 옮긴 한국어 표현입니다. 원점수(0–25) × 4 = 0–100, 해석 구간은 28 이하 · 29–50 · 51 이상, 직전 체크 대비 10점 이상 차이를 ‘의미 있는 변화’로 표시합니다. 진단이 아니며, 28 이하에서는 도움 받을 곳을 함께 안내합니다.

## 시각화

### 마음 지형도 (`lib/terrain.ts`, `components/charts/terrain-map.tsx`)

척도 점수를 봉우리 높이로 삼아 등고선 지도를 그립니다. 모듈마다 한 지역(반응 패턴 8봉우리, 방어기제 3수준, 성격 5요인 5봉우리, 관계 애착 2봉우리)을 차지하고, 좌표는 `data/terrain-layout.ts`에 고정되어 있습니다.

```text
높이장: z(x, y) = Σ (점수/100) · exp(−d² / 2σ²)  (σ = 0.075, 가로는 화면비 보정) + 고정 잔물결(난수 없음)
등고선: 100×62 격자에서 마칭 스퀘어, 11개 높이(0.12–0.92), 끝점은 격자 모서리 ID로 이어 붙임
길:     성립한 모듈 간 연결 해석의 근거 척도를 잇는 점선(방어기제 척도는 해당 수준 봉우리로)
```

- 높이는 응답에서 그 경향이 드러난 정도이며 좋고 나쁨이 아님을 지도 옆에 항상 안내합니다.
- 봉우리를 누르거나(키보드: Tab, 방향키로 이웃 봉우리, Enter) 가리키면 설명·점수 구간·연결된 해석이 열리고 관련 없는 곳은 흐려집니다. 같은 값은 화면 읽기 프로그램용 표로도 제공합니다.
- 홈 대시보드(축소판), 모듈 결과 화면(해당 지역 확대), 기록과 변화(이전 기록 점선 겹치기), PNG 포스터에서 같은 모델을 씁니다. 지형은 브라우저에서만 계산해 hydration 차이를 피합니다.
- 좁은 화면에서는 지도를 좌우로 밀어 봅니다.

### 모듈별

- 반응 패턴: Recharts 레이더, 상위 특징, 개인 반응 흐름, 차원 상호작용 카드, 차원별 계산 근거
- 방어기제: 수준별 점수 타일과 상대 구성비 막대, 무게중심 스펙트럼, 15개 방어 사다리, 개인 평균 대비 발산 막대, 자주 꺼내는 방어 카드(기능·비용·예시·성장 방향), 이미 가진 자원, DMRS 7단계 위계 사다리(단계별 몫·평균·방어 칩, 왼쪽 레일에 점수 가중 평균 수준 표시, 묻지 않는 4·2단계는 점선)
- 성격 5요인: 양극 스펙트럼(가운데 범위 음영), 양쪽 강점과 살펴볼 점
- 관계 애착: 관계 불안 × 친밀 회피 평면 위 위치(사분면 이름 없음), 축별 해석, 시점 비교 시 이전 위치 표시
- 점수의 확실도(모든 모듈): 척도마다 문항 응답(역채점 후)을 점으로, ±1 표준오차 범위를 띠로 표시하고 ‘문항끼리 일치 / 대체로 일치 / 문항마다 엇갈림’을 붙입니다. 프로필 분석(Cronbach & Gleser, 1953)의 높이(척도 평균)와 퍼짐(척도 표준편차)을 함께 보여줍니다. 모집단 신뢰구간이 아니라 내 응답 안의 일치 정도입니다
- 통합: 나 → 모듈 → 요약으로 이어지는 4방향 마인드맵(좁은 화면에서는 목록), 모듈 간 연결 해석 20개 규칙

밝은·어두운 테마(기기 설정 따르기 포함)를 지원하며, 어두운 테마의 수준 색상(`#33a070`, `#cc7f22`, `#5b8ad8`)도 따로 검증했습니다. 모든 차트는 같은 수치를 텍스트로도 보여주며, 색만으로 정보를 구분하지 않습니다. 수준 색상(`#2f8a62`, `#d4882a`, `#4f7cc4`)은 색각 이상 시뮬레이션 검증을 거쳤고 항상 이름과 함께 표시합니다.

## 채점과 해석

```text
공통 Likert 엔진 (lib/likert-engine.ts)
응답: 정수 0–4, 역채점: 4 − 응답
척도 점수: round(100 × Σ(가중치 × 채점값) / (4 × Σ가중치))
점수 구간: 0–24 드묾 · 25–49 가끔 · 50–74 자주 · 75–100 두드러짐
```

- 방어 수준 점수: 해당 수준 모든 문항의 같은 방식 평균
- 무게중심: (3A + 2I + 1M) / (A + I + M), 1–3을 0–100 위치로 변환. DMRS의 ODF에서 착안한 참고 지표
- DMRS 7단계 위계(Perry, 1990; DSM-IV 방어기능척도): 7 높은 적응(소속·예상·유머·승화·억제), 6 강박 수준(주지화·취소), 5 기타 신경증 수준(반동형성·전치), 3 부인 수준(부인·투사·합리화), 1 행동 수준(행동화·수동공격·회피·철수). 단계의 몫 = 단계 방어 점수 합 ÷ 전체 합(합 100), 점수 가중 평균 수준 = Σ(단계 × 점수) ÷ Σ점수(1–7). ODF 구조를 자기보고 점수에 옮긴 참고 지표로, 원 도구의 규준과 비교할 수 없음
- 개인 평균 대비: 각 방어 점수 − 15개 점수의 평균(응답 스타일 영향 완화)
- 두드러진 특징: 50점 이상 중 최대 3개, 앞 순위와 5점 이내는 ‘비슷한 수준’ 표시
- 상호작용·연결 해석·실천 추천: 관련 척도가 모두 63 이상(또는 37 이하)일 때만 표시, 근거 점수 함께 제시
- 점수의 확실도: 척도 문항의 역채점 후 값(0–4) 표준편차 SD, 범위 = 점수 ± (SD ÷ √문항 수) × 25(0–100으로 자름). SD ≤ 0.8 일치, ≥ 1.3 엇갈림
- 웰빙(WHO-5): 원점수 × 4, 구간 ≤28 · 29–50 · ≥51, 직전 대비 |차이| ≥ 10이면 의미 있는 변화, 문항 응답 0–1은 ‘돌봐 줄 영역’으로 표시
- 응답 패턴 참고: 모든 응답 동일, 평균 3.5 이상/0.5 이하, 정·역방향 문항 불일치 지수 0.5 이상(척도별 |정방향 평균 + 역방향 평균 − 4| ÷ 4의 평균)일 때 해석 주의 안내(결과는 무효화하지 않음)

| 모듈 | 질문지 버전 | 채점 버전 |
| --- | --- | --- |
| 반응 패턴 | `selfmap-likert-32-v1` | `weighted-likert-v1` |
| 방어기제 | `selfmap-defense-45-v1` | `defense-profile-v1` |
| 성격 5요인 | `selfmap-traits-20-v1` | `trait-profile-v1` |
| 관계 애착 | `selfmap-attachment-12-v1` | `attachment-profile-v1` |

채점·해석 함수는 같은 입력에 같은 결과를 반환하는 순수 함수입니다. 누락 응답을 0으로 대체하지 않고, 잘못된 값·ID·중복 응답·문항 데이터는 거부합니다. 설명 문구는 점수 구간과 규칙에 연결된 정적 데이터이며 LLM을 사용하지 않습니다.

## 공유 링크

`/results`의 ‘상담자와 함께 보기’는 완료한 모듈의 응답을 `#s1.<모듈>-<질문지 버전>-<0–4 숫자열>` 형식으로 URL 조각에 담습니다. 조각은 서버로 전송되지 않으며, 받은 사람의 브라우저가 같은 계산 함수로 결과를 다시 만듭니다. 버전·문항 수·값이 하나라도 맞지 않으면 열리지 않습니다. 링크를 가진 사람은 누구나 결과를 볼 수 있다는 점을 만들기 전에 안내합니다(`lib/share.ts`).

## 설치형 앱과 오프라인

`app/manifest.ts`와 `public/sw.js`로 홈 화면에 설치할 수 있고, 한 번 연 화면은 오프라인에서도 열립니다. 서비스 워커는 페이지 이동을 네트워크 우선(온라인이면 항상 최신), 해시가 붙은 정적 파일만 캐시 우선으로 처리하며 `/api/`와 다른 출처 요청은 건드리지 않습니다. 사용자 데이터는 캐시하지 않습니다(응답·기록은 원래대로 브라우저 저장소에만 있음). `next.config.ts`에서 보안 헤더(nosniff, X-Frame-Options DENY, Referrer-Policy, Permissions-Policy)와 `sw.js` 무캐시·CSP 헤더를 설정합니다.

## 선택 기능: AI 해설

기본값은 꺼짐입니다. 운영자가 서버 환경 변수 `SELFMAP_AI_EXPLAIN=on`과 Anthropic 자격 증명(`ANTHROPIC_API_KEY` 등)을 설정하면 `/results`에 ‘AI 해설 받아 보기’ 카드가 나타납니다.

- 사용자가 전송 내용을 확인하고 동의 체크 후 버튼을 누를 때만, 완료한 모듈의 **척도 ID와 0–100 점수만** `/api/explain`으로 보냅니다. 문항 응답·마음 기록·저장 기록·날짜는 보내지 않습니다.
- 서버는 본문을 다시 검증(알려진 척도·정수 점수·동의 플래그·8KB 상한)하고 공식 SDK(`@anthropic-ai/sdk`)로 `claude-opus-5-5`에 요청합니다. JSON 스키마 구조화 출력, 정책 거절 시 서버 기본 대체 모델(`fallbacks: "default"`)을 사용합니다.
- 응답은 서버와 화면에서 다시 검증합니다. **숫자가 하나라도 있거나**(점수 재작성 방지) 진단·병리·유형 단정 표현이 있으면 버리고 규칙 기반 해석만 보여줍니다. 점수는 바뀌지 않으며 해설은 저장하지 않습니다.
- 요청 본문은 로그에 남기지 않습니다. 구현: `lib/explain.ts`(순수 검증·프롬프트), `lib/explain-claude.ts`(서버 전용 호출), `app/api/explain/route.ts`.

## 화면 구성과 사용성

- **디자인 시스템 v4**: 안개빛 종이(`#f5f4f8`)와 보랏빛 잉크(`#4b3f8f`), 제목은 Hahmlet, 본문은 IBM Plex Sans KR(`next/font`가 빌드 때 받아 같은 출처에서 제공). 본문 15–16px, 최소 12px. 색은 `app/globals.css`의 토큰으로만 쓰고 어두운 테마는 토큰 값만 바꿉니다. 방어 수준 색은 기존 검증 값을 유지합니다.
- **PC**: 왼쪽 사이드바(탐색·도구·안심 묶음, 지도 완성도 위젯, 테마). `Ctrl/⌘ + K` 또는 `/`로 빠른 이동 창(화면·바로 하기·테마 전환, 방향키·Enter).
- **모바일·태블릿(1023px 이하)**: 위쪽 머리말(찾기, 테마 전환)과 아래 탭(홈·질문·지형도·기록·더보기). 더보기 시트에 나머지 도구와 지도 완성도.
- **설문**: 답을 고르면 다음 문항으로 자동 이동(기본 켬, 이 기기에 기억), 숫자 키 0–4와 Enter 안내.
- **강점과 살펴볼 점** (`lib/balance.ts`): 이미 계산된 점수와 정적 문구만 모아 양쪽을 같은 무게로 보여줍니다. 출처(모듈 간 연결·각 모듈)마다 번갈아 최대 5개씩.
- **지도 이야기** (`lib/terrain-story.ts`): 지형도를 고정 문장 틀로 풀어 씁니다(가장 높은 봉우리, 지역별 높낮이, 낮은 성격 축의 반대쪽 성향, 지역 사이의 길). 문장 속 숫자는 봉우리 점수와 그 차이뿐이며, 문장에 올리면 지도에서 해당 봉우리가 또렷해집니다.
- **글자 크기**: 보통·크게(1.12배). 사이드바·더보기·내 데이터·빠른 이동 창에서 바꾸며 이 기기에만 기억합니다. CSS의 모든 글자 크기는 `--fs` 배율을 곱합니다.
- **이번 주 카드**(홈 대시보드): 월–일 중 기록·연습한 날, 기록 수, 자주 적은 감정.
- **기록 속 연결** (`lib/journal-patterns.ts`): 마음 기록 3개 이상이면 감정 → 바란 것 흐름(생키 다이어그램, 띠 굵기 = 함께 적힌 횟수)과 요일 × 시간대(새벽·오전·오후·저녁) 격자(칸 진하기 = 기록 수, 숫자 = 평균 강도)를 보여줍니다. 주간 돌아보기에도 그 주의 흐름이 나옵니다.
- **결과 화면 바로가기**: 모듈 결과 화면 위쪽에 섹션으로 바로 가는 고정 바, 해당 모듈 지역을 확대한 지형도.
- **모바일 설문**: 이전·다음 버튼이 아래 탭 바로 위에 붙어 있어 엄지로 누르기 쉽습니다. 긴 모듈(30문항 이상)은 절반 지점에서 쉬어 가도 된다는 안내가 나옵니다.
- **키보드**: 상황 반응 숫자 키 1–5, 방어기제 찾기 연습 1–4와 Enter, 마음 기록 `Ctrl/⌘ + Enter` 저장, 지형도 방향키 이동.
- **기록의 리듬** (`lib/journal-calendar.ts`): 최근 12주 월요일 시작 달력. 칸의 진하기는 기록 수일 뿐 감정의 좋고 나쁨이 아닙니다. 이어서 기록한 날 수도 함께 보여줍니다.

## 구조

```text
types/            psychology(반응 패턴) · assessment(공통 Likert) · defense · traits (애착 ID는 data/attachment.ts)
data/             문항, 척도 메타데이터, 해석 문구, 규칙, 연습, 학습 콘텐츠 (계산 없음)
lib/              likert-engine, scoring, defense-analysis, trait-analysis, attachment-analysis, reaction-insights,
                  integration, mind-map, terrain, balance, journal-calendar, journal-patterns, terrain-story, practice, journal, snapshots, backup, session (순수 함수)
lib/*-store.ts    sessionStorage·localStorage와 React 상태 연결 (클라이언트)
components/       questionnaire, module-hub, charts/, results/, journal/, history/, practice-board, data-manager
app/              App Router 경로, globals.css(디자인 시스템 v4: 토큰 기반 밝은·어두운 테마)
tests/            엔진·모듈·방어 분석·해석 규칙·연습·기록·스냅숏·백업 테스트
docs/             v2-design.md, milestones.md, implementation-plan.md
```

테스트는 TypeScript 컴파일러와 Node.js 내장 test runner를 사용합니다. 기존 의존성(Next.js, React, Recharts, Tailwind) 외에 새 의존성을 추가하지 않았습니다. `deepzone/`은 별개 프로젝트이며 린트·타입체크 대상에서 제외합니다.
